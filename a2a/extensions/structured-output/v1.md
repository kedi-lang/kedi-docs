# Kedi A2A Structured Output Extension v1

**Extension URI:**
`https://docs.kedi-lang.org/a2a/extensions/structured-output/v1/`

This optional A2A extension lets a Kedi client request a JSON-Schema result from
a Kedi-served agent. Generic A2A text invocation remains unchanged.

## Agent Card Declaration

An implementation supporting per-request schemas advertises an
`AgentExtension` with the extension URI and these parameters:

```json
{
  "version": 1,
  "mode": "request-schema",
  "schemaDialect": "https://json-schema.org/draft/2020-12/schema",
  "maxSchemaBytes": 32768,
  "resultArtifactName": "kedi-structured-output"
}
```

Clients accept `mode` values `fixed` and `request-schema`. Kedi's v1 server
publishes `request-schema`. The extension is optional for raw text requests.

## Request

For a structured request, the client must:

1. include the extension URI in `Message.extensions`;
2. request the `application/json` output mode; and
3. place this object in `SendMessageRequest.metadata`:

```json
{
  "kediStructuredOutput": {
    "version": 1,
    "schema": {
      "type": "object",
      "properties": {
        "answer": {"type": "string"}
      },
      "required": ["answer"],
      "additionalProperties": false
    }
  }
}
```

The UTF-8 JSON encoding of `schema` must not exceed the advertised limit.
Kedi validates the schema before invoking the served adapter. Remote `$ref` and
`$id` resolution are unsupported, schema nesting is bounded, and invalid
schemas fail the task rather than reaching a model.

## Successful Result

The completed task contains one final artifact with:

- name `kedi-structured-output`;
- the extension URI in `Artifact.extensions`;
- media type `application/json`; and
- one data part containing the value that validates against the request schema.

The server validates the result before completing the task. The client validates
it again before assigning Kedi captures. Progress data, unrelated artifacts,
and plain text are never interpreted as the typed result.

## Failure Behavior

- A structured request to a peer that does not advertise the extension fails
  before the task is sent.
- A missing, malformed, oversized, wrongly named, or schema-invalid result fails
  without partial capture assignment.
- The extension does not authorize tools, transfer local configuration, or
  imply support for Kedi artifacts.
- v1 does not define repair-model retries, partial structured fields, remote
  schema references, or usage/cost accounting.

The task and context lifecycle otherwise follows A2A v1 semantics.
